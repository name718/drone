# 02 机械尺寸草模

## 目标

用 CAD 验证器件能否放下、重心是否合理、结构能否装配和维护。

## 主要任务

- 建立电机中心距、螺旋桨扫掠范围和机臂模型；
- 加入电池、电调、飞控和接收机的真实包络尺寸；
- 确定 PCB 外形、安装孔、螺柱高度和线束方向；
- 预留 3D 打印件的装配间隙、保护结构和维修空间。

## 输出物

尺寸草模、安装孔位图、重心估算、器件布局图。此阶段不追求外观和轻量化。

## V1 成品方案

V1 的 130 mm 方案比例不合理，已停止使用并保留作对比：[机械成品方案.blend](机械成品方案.blend)。V2 到 V4 为中间验证版本。当前装配与打印基线为 [机械成品方案-V5.blend](机械成品方案-V5.blend)。

### 1. 机架三维几何实测参数（基于 lower_frame-V5.stl 实测）

| 项目 | 参数 / 规格 | 说明 |
| :--- | :--- | :--- |
| **机架整体尺寸** | `153.28 mm × 153.28 mm × 5.40 mm` | 一体式 X 型底架，单连通壳体 |
| **电机对角中心距 (轴距)** | **`180.0 mm`** | 电机安装中心位于 `(±63.64, ±63.64)` |
| **机臂宽度** | `16.0 mm` | 结构刚度与轻量化兼顾 |
| **电机座外径** | `26.0 mm` | 提供电机底部撞击防护 |
| **电机安装孔位** | **`12.0 mm × 12.0 mm` 正方形四孔** | **M2 螺丝孔（孔径 2.3 mm）** |
| **电机中心避让孔** | **`8.4 mm` 直径** | 预留电机下部轴承及 C 扣卡簧旋转避让 |
| **螺旋桨包络** | **3.0 ~ 3.5 英寸** | 3.5 英寸（88.9 mm）桨尖间隙约 38.4 mm，空间充裕 |
| **飞控/电调中心堆叠孔** | **`30.5 mm × 30.5 mm`** | **M3 螺柱孔**（坐标 `±15.22, ±15.23`） |
| **电池安装槽** | 4 个 `5.0 mm × 12.0 mm` 扎带槽 | 适配 10mm 宽魔术贴扎带，底置纵向固定 |
| **电池包络空间** | 2S 锂电池，约 `60 mm × 30 mm × 17 mm` | 推荐 450mAh ~ 850mAh 2S LiPo |
| **设备层级** | 下置电池 -> 居中四合一电调 -> 上层飞控 | 飞控使用 36×36mm 减震泡棉贴装或 M3 软柱隔离 |

### 2. 配套电机详细选型与约束参数

机架电机座已严格固定为 **`12×12 mm M2`** 规格，选购电机时必须严格匹配以下参数：

| 选型要素 | 推荐规格 / 要求 | 选型与避坑要点 |
| :--- | :--- | :--- |
| **电机型号级别** | **1404 / 1504 / 1505**（首选 1404） | 1404 为 2.5~3.5 寸机架黄金动力，单颗重约 9g，响应灵敏 |
| **安装孔距约束** | **必须为 `12mm × 12mm` (M2 螺丝)** | ⚠️ **严禁购买 9×9mm 孔距电机**（部分 1103/1204 为 9mm 孔） |
| **KV 值 (2S 动力)** | **3800KV ~ 4500KV** (推荐 4500KV) | 搭配 7.4V 2S 电池与 3.0/3.5 寸三叶桨，推重比最佳 |
| **KV 值 (3S 动力备选)** | **2800KV ~ 3500KV** | 如后续升级 3S 电池，需选用较低 KV |
| **输出轴 / 桨座** | **T-Mount (1.5mm 轴心 + 2×M2 螺丝孔)** | 适配乾丰 Gemfan 3016 / 3520 等轻量化三叶桨 |
| **配套紧固件** | M2×6mm 扁圆头内六角螺丝 | 固定电机至 5.4mm 打印机臂底座 |

打印件 [lower_frame-V5.stl](打印件/lower_frame-V5.stl) 几何实测：
- 拓扑状态：单对象、单连通壳体、非流形边 0、开放边界 0；
