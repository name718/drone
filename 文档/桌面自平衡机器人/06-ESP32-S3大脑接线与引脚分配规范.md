# 🧠 桌面双轮自平衡智能机器人：ESP32-S3 大脑接线与硬件引脚规范

> **版本**：V1.0  
> **更新日期**：2026-08-28  
> **主控模组**：ESP32-S3-WROOM-1 / ESP32-S3-N16R8 (16MB Quad/Octal SPI Flash + 8MB Octal PSRAM)  
> **功能定位**：机器人高级智能大脑 —— 负责语音唤醒、大模型流式对话 (ASR + LLM + TTS)、OLED 动态拟人表情渲染、Wi-Fi/蓝牙通信，并通过 UART 向底层 STM32G473 主控下发运动指令。

---

## 1. ⚡ 电源与供电架构规范

```text
【调试阶段】电脑 USB (Type-C) ──> ESP32-S3 板载 LDO ──┬──> 5V 输出 ──> MAX98357A 功放 (Vin)
                                                    └──> 3.3V 输出 ─┬──> INMP441 麦克风 (VDD) ⚠️严禁5V
                                                                    └──> OLED 屏幕 (VCC)

【整车阶段】2S 锂电池 (7.4~8.4V) ──> 板载 SY8120 DCDC ──> +5V ──> ESP32-S3 5V 引脚
```

### ⚠️ 电源核心安全红线
1. **INMP441 麦克风必须接 `3.3V`**：其 MEMS 芯片耐压最高 3.6V，接 5V 会立即永久烧毁。
2. **MAX98357A 功放推荐接 `5V`**：5V 供电下推 4Ω 3W 腔体喇叭音量更充沛且不易产生削波失真；接 3.3V 亦可工作但音量稍小。
3. **共地原则 (GND)**：所有模块（功放、麦克风、OLED、STM32）的 `GND` 必须全部连通到 ESP32-S3 的 `GND`。
4. **防电源倒灌**：开发阶段使用 Type-C 连电脑供电时，**严禁**同时向开发板排针的 5V/3.3V 灌入外部电源。

## 2. 🎛️ 完整引脚级连接网表 (Pin-to-Pin Mapping)

本方案已严格避开 ESP32-S3-N16R8 内部 **8MB Octal PSRAM / Flash 所占用的高速引脚（GPIO 26, 33~37）** 以及 **USB/JTAG 调试引脚（GPIO 19, 20）**。

### 2.1 🎙️ 音频输入：INMP441 全向数字麦克风 (I2S0 RX)

| INMP441 模块引脚 | ESP32-S3 引脚 | 信号类型 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **VDD** | **`3.3V`** | 电源输入 | 3.3V 供电（⚠️ **严禁接 5V**） |
| **GND** | **`GND`** | 电源地 | 信号地与电源参考 |
| **SD** | **`GPIO 4`** | I2S0_DATA_IN | 录音串行数字音频数据流 |
| **WS** | **`GPIO 5`** | I2S0_WS / LRCK | 左右声道字选择时钟 |
| **SCK** | **`GPIO 6`** | I2S0_BCK / SCLK | 位时钟信号 |
| **L/R** | **`GND`** | 声道配置 | 接 GND 选择左声道输出（默认配置） |

### 2.2 🔊 音频输出：MAX98357A 功放 + 3525 腔体喇叭 (I2S1 TX)

| MAX98357A 模块引脚 | 目标连接 | 信号类型 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **Vin** | **ESP32 `5V`** (或 `VBUS`) | 电源输入 | 功放主电源（推荐 5V） |
| **GND** | **ESP32 `GND`** | 电源地 | 电源地 |
| **DIN** | **`GPIO 15`** | I2S1_DATA_OUT | 播放串行数字音频数据流 |
| **BCLK** | **`GPIO 16`** | I2S1_BCK | 位时钟信号 |
| **LRC** | **`GPIO 17`** | I2S1_WS / LRCK | 左右声道字选择时钟 |
| **GAIN** | **悬空 (NC)** | 增益配置 | 默认浮空为 9dB 增益（失真小、动态佳） |
| **SD / SD_MODE** | **悬空 (NC)** | 使能/模式 | 默认浮空为使能状态，输出 (L+R)/2 单声道混合 |

| **绿色端子 `-`** | **3525 喇叭 黑线** | 模拟功放输出 | 剥线插入螺丝端子拧紧 |

### 2.4 🔗 下位机通信预留：与 STM32G473 主控串口 (UART2)

| ESP32-S3 引脚 | STM32G473 主控引脚 | 信号类型 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **`GPIO 43` (TX)** | **`PA3` (USART2_RX)** | 3.3V TTL UART | 大脑下发速度/转向/动作指令至平衡底盘 |

## 3. 🚫 内部保留引脚与防冲突表 (ESP32-S3-N16R8)

开发固件与扩展外部外设时，**绝对不能占用**以下专用引脚：

| 引脚编号 | 芯片内部用途 | 禁止外接原因 |
| :--- | :--- | :--- |
| **GPIO 33 ~ 37** | **Octal PSRAM (8MB OPI)** | 内部 8 线高速 PSRAM 总线，占用会导致系统崩溃死机 |
| **GPIO 26** | **PSRAM 片选 (SPICS1)** | PSRAM 专有片选 |
| **GPIO 19, 20** | **USB D- / D+ (JTAG/OTG)** | 原生 USB 调试/下载通道 |
| **GPIO 0** | **BOOT 引脚** | 上电采样启动模式（低电平进下载模式） |
| **GPIO 45, 46** | **VDD_SPI / 启动配置** | 电源域与启动配置 Strapping 引脚 |

## 4. 🧩 固件工程配置基准 (PlatformIO / ESP-IDF)

### 4.1 PlatformIO `platformio.ini` 核心配置建议

```ini
[env:esp32-s3-devkitc-1]
platform = espressif32
board = esp32-s3-devkitc-1
framework = arduino

; 启用 16MB Flash 与 8MB OPI PSRAM
board_build.flash_mode = qio
board_build.f_flash = 80000000L
board_build.arduino.memory_type = qio_opi
board_upload.flash_size = 16MB

; 编译选项：开启 PSRAM 内存分配支持
build_flags = 
    -DBOARD_HAS_PSRAM
    -mfix-esp32-psram-cache-issue
    -DCORE_DEBUG_LEVEL=3

; 串口配置
monitor_speed = 115200
upload_speed = 921600
```
