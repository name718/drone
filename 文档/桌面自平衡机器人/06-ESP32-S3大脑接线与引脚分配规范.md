# 桌面双轮自平衡智能机器人：ESP32-S3 大脑接线与硬件引脚规范

> **版本**：V2.0 (全实机调试验证版)  
> **更新日期**：2026-10-02  
> **主控模组**：ESP32-S3-WROOM-1 / ESP32-S3-DevKitC-1-N16R8 (16MB Flash + 8MB Octal PSRAM)  
> **功能定位**：机器人高级智能大脑 —— 负责语音交互、动态赛博电子眼表情、双轴云台姿态互动、Wi-Fi 组网，并通过高频 UART2 向底层 STM32G473 主控下发运动指令。

---

## 1. 电源与供电架构规范

```text
【调试阶段】电脑 USB (Type-C) ──> ESP32-S3 板载 LDO ──┬──> 5V 输出 ──> MAX98357A 功放 (Vin)
                                                    └──> 3.3V 输出 ─┬──> INMP441 麦克风 (VDD) 严禁5V
                                                                    └──> 1.8寸 TFT 彩屏 (VCC)

【整车阶段】2S 锂电池 (7.4~8.4V) ──> 板载 SY8120 DCDC ──> +5V ──> ESP32-S3 5V 引脚 (J_ESP32 Pin 1)
【舵机供电】2S 锂电池 (7.4~8.4V) ──> 外部 LM2596 (6.12V) ──> 两个 SG90 舵机正极 (严禁接ESP32排针)
```

### 电源核心安全红线
1. **INMP441 麦克风必须接 `3.3V`**：其 MEMS 芯片耐压最高 3.6V，接 5V 会立即永久烧毁。
2. **MAX98357A 功放接 `5V`（或 3.3V）**：5V 供电下推 4Ω 3W 腔体喇叭音量更充沛且不易产生削波失真；**严禁接到 6.12V LM2596 动力电**！
3. **SG90 舵机必须接外部 LM2596 (6.0V ~ 6.12V)**：双舵机峰值电流 > 1.2A，直接插 ESP32 排针会导致 ESP32 瞬间欠压反复重启甚至烧板载 LDO。
4. **共地原则 (GND)**：所有模块（功放、麦克风、TFT屏、舵机、STM32底盘）的 `GND` 必须全部连通到 ESP32-S3 的 `GND`。
5. **防电源倒灌**：开发阶段使用 Type-C 连电脑供电时，**切勿将底盘 J_ESP32 的 5V 杜邦线插到 ESP32 的 5V 上**（防止电脑 USB 与主控 DCDC 电源倒灌冲突）。

## 2. 完整引脚级连接网表 (Pin-to-Pin Mapping)

本方案已严格避开 ESP32-S3-N16R8 内部 **8MB Octal PSRAM / Flash 所占用的高速引脚（GPIO 26, 33~37）** 以及 **USB/JTAG 调试引脚（GPIO 19, 20）** 和 **USB-to-UART 桥接引脚（GPIO 43, 44）**。

### 2.1 视觉与表情：1.8寸 TFT 彩色液晶屏 (ST7735S 驱动, SPI2 总线)
> 替代了早期的 0.96 OLED，拥有 128×160 彩色点阵，支持高帧率赛博大眼表情渲染与声波电平跳动。

| TFT 屏幕引脚 | ESP32-S3 引脚 | 信号类型 | 功能说明 | 实测状态 |
| :--- | :--- | :--- | :--- | :---: |
| **GND** | **`GND`** | 电源地 | 信号地与电源参考 | 正常 |
| **VCC** | **`3.3V`** 或 **`5V`** | 电源输入 | 屏幕芯片与背光供电 | 正常 |
| **SCL / SCLK** | **`GPIO 12`** | SPI2_CLK | SPI 硬件时钟 | 正常 |
| **SDA / MOSI** | **`GPIO 11`** | SPI2_MOSI | SPI 硬件主出从入数据线 | 正常 |
| **RES / RST** | **`GPIO 10`** | GPIO_OUT | 硬件复位引脚 (低电平复位) | 正常 |
| **DC** | **`GPIO 13`** | GPIO_OUT | 数据 / 命令切换选择线 | 正常 |
| **CS** | **`GPIO 14`** | GPIO_OUT | SPI 硬件片选线 (低电平有效) | 正常 |
| **BLK / LED** | **`GPIO 21`** | GPIO_OUT | 背光控制引脚 (高电平点亮) | 正常 |

### 2.2 姿态与视觉云台：SG90 双轴舵机 (50Hz PWM 控制)
> 负责机器人头部水平转动与垂直俯仰动作。

| 舵机轴向 | 信号线 (黄/橙) | 电源正 (红) | 电源负 (棕/黑) | 范围与参数 |
| :--- | :--- | :--- | :--- | :--- |
| **水平旋转 (Pan)** | **`GPIO 1`** (LEDC_CH0) | **LM2596 `OUT+` (6.0V)** | **LM2596 `OUT-` (GND)** | 0° ~ 180°，中位 90° |
| **垂直俯仰 (Tilt)** | **`GPIO 2`** (LEDC_CH1) | **LM2596 `OUT+` (6.0V)** | **LM2596 `OUT-` (GND)** | 45° ~ 135°，中位 90° |

### 2.3 音频输出：MAX98357A 功放 + 3525 腔体喇叭 (I2S1 通道)
> 负责开机和弦音、音效播报与高保真语音合成。

| MAX98357A 模块引脚 | 目标连接 | 信号类型 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **Vin** | **ESP32 `5V`** (或 `VBUS`) | 电源输入 | 功放主电源（推荐 5V） |
| **GND** | **ESP32 `GND`** | 电源地 | 与整车共地 |
| **DIN** | **`GPIO 15`** | I2S1_DATA_OUT | 播放串行数字音频数据流 |
| **BCLK** | **`GPIO 16`** | I2S1_BCK | 位时钟信号 |
| **LRC** | **`GPIO 17`** | I2S1_WS / LRCK | 左右声道字选择时钟 |
| **GAIN** | **悬空 (NC)** | 增益配置 | 默认浮空为 9dB 增益（失真小、动态佳） |
| **SD / SD_MODE** | **悬空 (NC)** | 使能/模式 | 默认浮空为使能状态，输出 (L+R)/2 单声道混合 |
| **螺丝端子** | **3525 喇叭 红黑线** | 模拟功放输出 | 剥线插入螺丝端子拧紧 |

### 2.4 音频输入：INMP441 全向数字麦克风 (I2S0 通道)
> 负责 16kHz 语音采样、拍手声控识别与环境音量监测。

| INMP441 模块引脚 | ESP32-S3 引脚 | 信号类型 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **VDD** | **`3.3V`** | 电源输入 | 3.3V 供电（**严禁接 5V**） |
| **GND** | **`GND`** | 电源地 | 信号地与电源参考 |
| **SD** | **`GPIO 4`** | I2S0_DATA_IN | 录音串行数字音频数据流 |
| **WS** | **`GPIO 5`** | I2S0_WS / LRCK | 左右声道字选择时钟 |
| **SCK** | **`GPIO 6`** | I2S0_BCK / SCLK | 位时钟信号 |
| **L/R** | **`GND`** | 声道配置 | 接 GND 选择左声道输出（默认配置） |

### 2.5 大脑 -> 底盘通信总线 (UART2 跨芯片通信)
> 50Hz 周期性下发速度目标帧，双向心跳监控与底盘状态遥测。

| ESP32-S3 引脚 | STM32G473 主控引脚 | 信号类型 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **`GPIO 7` (TX)** | **`PA3` (USART2_RX)** | 3.3V TTL UART | 大脑下发速度/转向/动作指令至平衡底盘 |
| **`GPIO 8` (RX)** | **`PA2` (USART2_TX)** | 3.3V TTL UART | 底盘上报电池电压、姿态角、里程计与故障码 |
| **`GND`** | **`GND`** | 信号地 | 必须共地，确保串口电平基准一致 |

> **引脚迁移说明**：ESP32-S3 原生的 GPIO 43/44 为板载 USB-to-UART 桥接硬件直连引脚。为彻底消除连电脑烧录/打印与外接串口的电平冲突，跨芯片通信已正式确立使用 **`GPIO 7 (TX)` 和 `GPIO 8 (RX)`**。

## 3. 内部保留引脚与防冲突表 (ESP32-S3-N16R8)

| 引脚编号 | 芯片内部用途 | 禁止外接原因 |
| :--- | :--- | :--- |
| **GPIO 33 ~ 37** | **Octal PSRAM (8MB OPI)** | 内部 8 线高速 PSRAM 总线，占用会导致系统崩溃死机 |
| **GPIO 26** | **PSRAM 片选 (SPICS1)** | PSRAM 专有片选 |
| **GPIO 19, 20** | **USB D- / D+ (JTAG/OTG)** | 原生 USB 调试/下载通道 |
| **GPIO 43, 44** | **U0TXD / U0RXD** | 板载 CH343/CP2102 串口芯片直连脚 |
| **GPIO 0** | **BOOT 引脚** | 上电采样启动模式（低电平进下载模式） |
| **GPIO 45, 46** | **VDD_SPI / 启动配置** | 电源域与启动配置 Strapping 引脚 |
