## 1. 全机供电树与“四大防烧红线”

### 1.1 电源拓扑架构图
```text
【2S 动力锂电池】(7.4V ~ 8.4V)
  │
  ├──> [外部 LM2596 降压模块] ──稳压输出 6.12V──┬──> 主控板 H1 接口 ──> TB6612 [VM 动力引脚]
  │                                                └──> 两个 SG90 舵机 [红色正极 VCC]
  │
  └──> [主控板 J1 电池输入]
         │
         ├──> 板载 SY8120 DCDC ──输出 +5.0V──┬──> J_ESP32 接口 [Pin 1: +5V] (整车独立运行时供电)
         │                                    └──> 板载 ME6211 LDO ──输出 +3.3V──┬──> STM32G473 主控
         │                                                                       ├──> ICM-42605 陀螺仪
         │                                                                       ├──> 左右霍尔编码器
         │                                                                       └──> TB6612 [VCC 逻辑引脚]
         │
         └──> 电池采样电阻分压 (R8:10k + R17:4.7k) ──> STM32 [PC0 / ADC1] (实时电量监测)
```

### 1.2 绝对不可触碰的“四大防烧红线”
1. **INMP441 麦克风严禁接 5V**：其工作电压上限为 3.6V，**必须且只能接 ESP32 的 `3.3V`**，误接 5V 会瞬间击穿烧毁！
2. **MAX98357A 功放严禁接 6.12V 动力电**：功放芯片耐压上限 5.5V，**必须接 ESP32 的 `5V`（或 3.3V）**，绝不可接到 LM2596 的 6V 动力端！
3. **SG90 舵机供电严禁接 ESP32 板载排针**：两个舵机堵转电流峰值超过 1.2A，直接插 ESP32 排针会导致 ESP32 瞬间欠压反复重启甚至烧板载 LDO，**必须接 LM2596 输出端（6.0V ~ 6.12V）**！
4. **调试阶段防电源倒灌**：当 ESP32 使用 Type-C 连电脑调试时，**切勿将主控板 J_ESP32 的 5V 杜邦线插到 ESP32 的 5V 上**（防止电脑 USB 与主控 DCDC 电源倒灌短路冲突）。

## 3. 下位机（STM32G473RCT6 底盘）完整接线表

### 3.1 动力与主供电输入端子
- **`J1` (2Pin 电池端子)**：
  - 引脚 1（方孔/红线）：`VBAT`（2S 锂电池 7.4V ~ 8.4V）
  - 引脚 2（圆孔/黑线）：`GND`（电池负极共地）
- **`H1` (2Pin 动力端子)**：
  - 引脚 1（方孔/红线）：`VM_6V`（接 LM2596 输出的正 6.12V）
  - 引脚 2（圆孔/黑线）：`GND`（接 LM2596 输出的负 GND）

### 3.4 左右轮高精度磁编码器接口
> 采用硬件正交解码模式，前进时两轮数值均严格正向递增。

#### 左轮编码器 (主控板 `J_ENC_L`, 4Pin):
1. **第 1 脚 (`+3V3`)**：**黑色线** (编码器电源正)
2. **第 2 脚 (`GND`)**：**蓝色线** (编码器地线)
3. **第 3 脚 (`ENC_L_A`)**：**绿色线** -> STM32 **`PA0`** (TIM2_CH1)
4. **第 4 脚 (`ENC_L_B`)**：**黄色线** -> STM32 **`PA1`** (TIM2_CH2)

#### 右轮编码器 (主控板 `J_ENC_R`, 4Pin):
1. **第 1 脚 (`+3V3`)**：**黑色线** (编码器电源正)
2. **第 2 脚 (`GND`)**：**蓝色线** (编码器地线)
3. **第 3 脚 (`ENC_R_A`)**：**绿色线** -> STM32 **`PA8`** (TIM1_CH1)
4. **第 4 脚 (`ENC_R_B`)**：**黄色线** -> STM32 **`PA9`** (TIM1_CH2)

---

### 3.5 板载六轴姿态传感器 (ICM-42605, SPI1 总线)
> 板载贴片芯片，无需外部接线，供查阅引脚映射：
- **`PA4`**：`IMU_CS`（片选，低有效）
- **`PA5`**：`IMU_SCK`（SPI1 时钟）
- **`PA6`**：`IMU_MISO`（SPI1 数据输入）
- **`PA7`**：`IMU_MOSI`（SPI1 数据输出）
- **`PC4`**：`IMU_INT1`（1000Hz 姿态数据就绪中断）

---

### 3.6 SWD 调试烧录接口 (`U2` / `J_SWD`, 4Pin)
> 连接 ST-Link V2 烧录器：
1. **`+3V3`**：接 ST-Link `3.3V`（目标板参考电压检测）
2. **`SWDIO`**：接 ST-Link `SWDIO`（STM32 `PA13`）
3. **`SWCLK`**：接 ST-Link `SWCLK`（STM32 `PA14`）
4. **`GND`**：接 ST-Link `GND`
