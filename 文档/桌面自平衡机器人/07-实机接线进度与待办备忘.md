## 2. ⚡ 电源与驱动总线映射表 (已全面通电验证)

### 2.1 动力电源供电链路
- **2S 锂电池 (7.4V ~ 8.4V)** ➔ 蓝色 LM2596 降压模块输入端 (`IN+ / IN-`)
- **LM2596 输出 (6.12V)** ➔ 主控板 **`H1` (2Pin)** ➔ 内部加粗铺铜 ➔ **`J2` 第 1 脚 (`VM_6V`)** ➔ TB6612 **`VM`**

### 2.2 控制逻辑与单片机供电链路
- **2S 锂电池 (7.4V ~ 8.4V)** ➔ 主控板 **`J1` (2Pin)** ➔ 板载 **`U11` (SY8120 降为 5.0V)** ➔ 板载 **`LDO2` (ME6211 降为 3.3V)** ➔ STM32、编码器、陀螺仪与绿色电源灯 **`LED1`**
- **J1 电压采样分压**：`VBAT` ➔ R8(10k) + R17(4.7k) ➔ STM32 `PC0` (ADC1)

### 2.3 红色 TB6612 ➔ 主控板 `J2` (10Pin) 控制总线
1. `VM_6V` ➔ `VM` (6.12V 动力电)
2. `+3V3` ➔ `VCC` (逻辑使能供电)
3. `GND` ➔ `GND`
4. `MOTOR_PWMA` ➔ `PWMA` (TIM3_CH1, PC6)
5. `MOTOR_AIN1` ➔ `AIN1` (PC8)
6. `MOTOR_AIN2` ➔ `AIN2` (PC9)
7. `MOTOR_PWMB` ➔ `PWMB` (TIM3_CH2, PC7)
8. `MOTOR_BIN1` ➔ `BIN1` (PA15)
9. `MOTOR_BIN2` ➔ `BIN2` (PB0)
10. `MOTOR_STBY` ➔ `STBY` (PB1, 高电平使能)

## 3. 🛠️ 现代化一键编译与烧录工具链

底盘固件位于 `firmware_chassis/`，基于轻量级 CMake + CMSIS 架构，已打通 Docker 与 ST-Link：

```bash
# 在终端任意路径执行此脚本，即可自动完成编译、生成 bin 并通过 ST-Link 烧录复位：
./scripts/flash_chassis.sh
```

- **编译容器**：`stm32-builder:latest`
- **编译器**：`arm-none-eabi-gcc 10.3.1` (C11/C++17, Cortex-M4F 硬件浮点使能)
- **编译耗时**：~ 1.5 秒
- **烧录工具**：`st-flash 1.8.0`（自动检测芯片 ID: 0x469，自动校验并复位）

1. **里程计/编码器方向校准**：确认小车向前推进时，左右编码器读数均为正向累加递增。

4. **跨芯片通信协议打通**：
   - 连接 `J_ESP32`（USART2, PA2 TX, PA3 RX），按照根目录 `robot_protocol.h` 与 ESP32-S3 大脑建立 50Hz 双向通信。
