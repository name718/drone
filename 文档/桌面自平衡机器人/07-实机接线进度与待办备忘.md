### 2.3 红色 TB6612 控制端 ➔ 主控板 `J2` 排母 (1x10P)

| `J2` 引脚 | 主板网络名称 | 对应 TB6612 引脚 | 状态 |

| **1 脚** (左侧方孔) | `VM_6V` | **`VM`** | ✅ 已连接 |
| **2 脚** | `+3V3` | **`VCC`** | ✅ 已连接 |
| **3 脚** | `GND` | **`GND`** | ✅ 已连接 |
| **4 脚** | `MOTOR_PWMA` | **`PWMA`** (STM32 PC6) | ✅ 已连接 |
| **5 脚** | `MOTOR_AIN1` | **`AIN1`** (STM32 PC8) | ✅ 已连接 |
| **6 脚** | `MOTOR_AIN2` | **`AIN2`** (STM32 PC9) | ✅ 已连接 |
| **7 脚** | `MOTOR_PWMB` | **`PWMB`** (STM32 PC7) | ✅ 已连接 |

### 2.4 左右轮编码器 ➔ 主控板 `J_ENC_L` 与 `J_ENC_R` (1x4P)
每个接口**第 1 脚为方形焊盘**：

- **左轮编码器 (`J_ENC_L`)**：
  - 第 1 脚 (方形, `+3V3`) ➔ ⚫ **黑色线 (VCC)**
  - 第 2 脚 (圆形, `GND`)  ➔ 🔵 **蓝色线 (GND)**
  - 第 3 脚 (圆形, `ENC_L_A`) ➔ 🟢 **绿色线 (C1)** (STM32 PA0)
  - 第 4 脚 (圆形, `ENC_L_B`) ➔ 🟡 **黄色线 (C2)** (STM32 PA1)

- **右轮编码器 (`J_ENC_R`)**：
  - 第 1 脚 (方形, `+3V3`) ➔ ⚫ **黑色线 (VCC)**
  - 第 2 脚 (圆形, `GND`)  ➔ 🔵 **蓝色线 (GND)**
  - 第 3 脚 (圆形, `ENC_R_A`) ➔ 🟢 **绿色线 (C1)** (STM32 PA8)
  - 第 4 脚 (圆形, `ENC_R_B`) ➔ 🟡 **黄色线 (C2)** (STM32 PA9)
