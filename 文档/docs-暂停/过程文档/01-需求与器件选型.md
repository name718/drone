# 01 需求与器件选型

本阶段先采用下面这套“能买到、容易调试、性能足够”的基线方案。后续只有在实测发现不满足需求时才更换器件，避免一开始反复选型。

## 首版目标

| 项目 | 基线目标 |
| --- | --- |
| 机架 | 约 180 mm，X 型四轴 |
| 电池 | 2S LiPo，约 850 mAh，目标包络 60 x 30 x 17 mm |
| 起飞重量 | 约 250~350 g（含电池） |
| 飞行模式 | 角度模式优先，后续增加自稳/定高实验 |
| 控制链路 | 2.4 GHz ELRS，CRSF UART |
| 图传 | 首版后装，使用成熟 5.8 GHz 模块 |
| 调试 | USB 串口 + SWD + Flash 日志 |

180 mm 是围绕 36 x 36 mm 自研飞控、电池、调试空间和桨尖间隙修正后的 V3 机械基线。实际器件尺寸确定后允许小幅调整。

## 推荐基线器件

| 模块 | 首选 | 选择理由 |
| :--- | :--- | :--- |
| **飞控 MCU** | **STM32G473RCT6** | 170MHz Cortex-M4F（DSP/FPU），256KB Flash / 128KB RAM；LQFP-64 封装及现有引脚连接与原 STM32G474RET6 兼容，保留 USB、SPI、UART、I2C、ADC、SWD 和 4 路电机输出 |
| IMU | ICM-42688-P | SPI 速度高，资料和驱动较完整，支持较高采样率 |
| 气压计 | BMP388 | 常见、体积小，适合高度变化观测 |
| 向下 ToF | VL53L1X 模块 | 先用模块降低首版 PCB 和光学布局难度 |
| 日志 Flash | W25Q128JV | SPI NOR，容量足够，驱动简单 |
| 5 V 降压 | MP1584EN 级 3 A Buck | 器件常见、外围简单；最终按图传峰值电流和温升验证 |
| 3.3 V LDO | 低噪声 600 mA 级 | 单独供 IMU 与气压计，降低数字电源噪声 |
| 接收机 | Happymodel EP1/同级 ELRS | 体积小，CRSF UART，资料和固件生态成熟 |
| 电调 | 2S 兼容四合一、20~30 A 级 | 留出电机峰值电流余量，先购买成熟模块 |
| 电机 | 1505 级，KV 值根据厂商 2S/3.5 英寸测试表确定 | 与 160 mm、3.5 英寸平台匹配，不能脱离桨和电池单独确定 KV |
| 螺旋桨 | 3.5 英寸，先购两种桨距测试 | 推力、噪声和电流需要实测，不能只按 KV 推断 |

5 V Buck 暂以 MP1584EN 级 3 A 方案为基线，但必须根据图传峰值电流、输入压降和温升实测确认；若电流或噪声不满足，再更换为更合适的同步 Buck。

## 遥控器基线

- STM32G030C8T6 主控；
- 双 3.3 V 霍尔摇杆，共四路 ADC；
- 两个三段开关、两个两段开关、两个功能按键和蜂鸣器；
- 1.8 英寸 ST7735 SPI TFT；
- 单节锂电池，IP5306 Type-C 充电与 5 V 升压，ME6211 生成 3.3 V；
- 通过 CRSF UART 连接成熟 ELRS 2.4 GHz 发射模块；
- 详细实现见 [ELRS 遥控控制器硬件落地](07-遥控器控制器硬件落地.md)。

## 必须先完成的校核

1. 下载所有候选器件数据手册，记录封装、尺寸、供电和工作温度；
2. 查电机在 2S、目标螺旋桨下的最大电流和推力，确认电调余量；
3. 用实际器件重量完成起飞重量和推力重量比估算；
4. 汇总 UART、SPI、I2C、定时器/DMA、USB、SWD 和电源接口分配；
5. 只有完成上述校核，才进入机械尺寸草模和飞控 PCB 设计。
