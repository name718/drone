# 03 飞控开发板（设计复核完成，待打样验证）

## 状态：原理图与 PCB 已同步为 STM32G473RCT6

飞控开发板主控已由 STM32G474RET6 替换为 **STM32G473RCT6**。两个器件均为 LQFP-64；原理图、PCB 位号、器件属性和网表已经同步。投板前检查结果为：PCB DRC 0 错误、48/48 网络已布通、无未布线网络。最终可飞性仍须通过实板供电、时钟、传感器和电机输出联调确认。

---

## 1. 核心设计规格与参数

- **主控 MCU**：**STM32G473RCT6**（LQFP-64，ARM Cortex-M4F，170MHz，DSP/FPU，256KB Flash，128KB SRAM）
- **立创器件编号**：`C529361`（扩展库器件）
- **兼容性约束**：硬件引脚与现有设计兼容；固件链接结果必须小于 256KB，链接脚本及芯片宏需切换为 STM32G473RCT6
- **板卡尺寸**：`36.0 mm × 36.0 mm`，双层板设计，板厚 `1.2 mm`（轻量化）
- **固定方式**：3M 高弹性减震泡棉胶安装（提供优异高频电机振动物理隔离）
- **阻焊与工艺**：白色阻焊 + 黑色丝印 + OSP 环保抗氧化高平整度无铅焊盘

## 2. 硬件功能子系统

| 模块 | 器件型号 | 接口 / 引脚网络 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **主控核心** | **STM32G473RCT6** | SWD (`PA13/PA14`), BOOT0 (`PB8`, Pin 61), NRST | 170MHz Cortex-M4F 飞控算法运算与各外设调度 |
| **外部时钟** | 8MHz / 12pF 贴片晶振 + 15pF C0G | `PF0-OSC_IN` / `PF1-OSC_OUT` (Pin 5/6) | 主系统时钟源 |
| **姿态传感器** | ICM-42605 (LGA-14) | SPI1 (`PA5~PA7, PA4_CS`), `PC4_INT` | 六轴陀螺仪与加速度计；固件须使用对应驱动 |
| **中高空气压计** | BMP388 (LGA-10) | I2C1 (`PB6_SCL`, `PB7_SDA`) | 气压高程与中高空自主定高 |
| **黑匣子日志** | W25Q128 (SOIC-8) | SPI2 (`PB13~PB15`, `PB11_CS`) | 16MB NOR Flash 飞行数据记录 |
| **动力输出** | 4 路 DShot600 + 47Ω | `PC6~PC9` (TIM3/TIM8 DMA), H1 8P | 4 路无刷电机控制 + 电池电压/电流采样 |
| **遥控接收机** | 4P 排针接口 | USART2 (`PA2_TX`, `PA3_RX`), +5V, GND | ELRS / TBS Crossfire 双向高速遥控 |
| **USB 调试** | 16Pin Type-C | `PA11_DM`, `PA12_DP`, CC1/CC2 5.1k, D1 | Betaflight 电脑调参及固件升级 |
| **降压供电** | SY8120IABC (Buck) | 2S 动力输入 -> `+5V 2A` 输出 | 驱动接收机、蜂鸣器及 LDO |
| **低噪供电** | ME6211C33 (LDO) | `+5V` -> `+3.3V 500mA` 超低噪声输出 | 专供给主控 MCU 及 IMU/气压计传感器 |
| **测压采样** | 10k/1k 精密分压 | `PA0 (ADC1_IN1)` | 动力电池实时电压监测与低电量告警 |
| **声光指示** | LED1(PWR), LED2(STATUS), S8050 | `PC13 (LED)`, `PB0 (BUZZER)` | 电源指示、飞控状态灯及蜂鸣器报警 |
| **扩展接口** | 4P ToF 激光定高接口 (H2) | `+3.3V`, `GND`, `I2C1_SCL`, `I2C1_SDA` | 预留机底激光毫米级低空定高扩展 |

## 3. PCB 制造与验证输出物

- ✅ **原理图设计**：严格 ERC 0 错误；未使用 MCU GPIO 已标记为 No-Connect，剩余 5 条提示为四脚晶振同名网络与 H1 器件标准化；
- ✅ **PCB 布局**：功能模块独立物理隔离，IMU 居中，功率回路极小化；
- ✅ **走线与 DRC**：48/48 网络贯通，未布线网络 0，DRC 0 错误；U7 两端关键走线已按新封装重接并加宽至 20mil；
- ✅ **双面铺铜**：Top Layer 与 Bottom Layer 完成连续完整的 GND 屏蔽铺铜；
- ✅ **生产备注**：LED2 已替换为蓝色 0603 LED `KT-0603B`（嘉立创/LCSC `C2288`），原理图、PCB 与 SMT BOM 已同步，极性保持一致；
- ⚠️ **联调门槛**：验证 8MHz 起振、3.3V/5V 纹波、ICM-42605 SPI/中断、四路 DShot、USB/SWD 和接收机串口后，才能签署“可飞”。
