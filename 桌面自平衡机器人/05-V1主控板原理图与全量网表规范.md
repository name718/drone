### 2.4 电源系统：U11 (SY8120IABC) 与 LDO2 (ME6211)

#### 1. U11：SY8120IABC 同步降压 DCDC (SOT-23-6)
* **1 脚 (BS)**：通过 **C2 (100nF 自举电容)** 跨接到 **6 脚 (LX)**；
* **2 脚 (GND)**：接 **`GND`**；
* **3 脚 (FB)**：接反馈分压中点（**R7 110k 接 +5V**，**R2 15k 接 GND**，分压计算公式：$V_{OUT} = 0.6\text{V} \times (1 + \frac{110\text{k}}{15\text{k}}) = 5.0\text{V}$）；
* **4 脚 (EN)**：接 **`VBAT`**（开启使能）；
* **5 脚 (IN)**：接 **`VBAT`**，输入端挂 **C8 (10uF) 到 GND**；
* **6 脚 (LX)**：串联 **L1 (4.7uH 功率电感)** 到 **`+5V`**，输出端挂 **C1 (10uF) 与 C3 (100nF) 到 GND**。

#### 2. LDO2：ME6211C33M5G-N 3.3V 稳压器 (SOT-23-5)
* **1 脚 (VIN)**：接 **`+5V`**，输入端挂 **C4 (10uF) 到 GND**；
* **2 脚 (VSS)**：接 **`GND`**；
* **3 脚 (CE)**：接 **`+5V`**（高电平使能）；
* **4 脚 (NC)**：打叉悬空；
* **5 脚 (VOUT)**：输出 **`+3V3`**，输出端挂 **C5 (10uF) 与 C6 (100nF) 到 GND**。

### 2.6 USBC2、晶振、LED 及分压采样电路

1. **USBC2 (TYPE-C-31-M-12)**：
   * `A1B12, B1A12, EH1~4` $\to$ **`GND`**；
   * `A4B9, B4A9` $\to$ **`USB_VBUS`**（经 **D1 肖特基二极管 B5819W** 单向导通至 **`+5V`**）；
   * `A5 (CC1)` $\to$ 经 **R9 (5.1k)** 接 **`GND`**；
   * `B5 (CC2)` $\to$ 经 **R4 (5.1k)** 接 **`GND`**；
   * `A6, B6 (DP)` $\to$ **`USB_DP`** (接 PA12)；
   * `A7, B7 (DN)` $\to$ **`USB_DM`** (接 PA11)；
   * `A8, B8 (SBU)` $\to$ 悬空打叉。
2. **X1 (8MHz 无源晶振)**：
   * `1 脚` $\to$ **`PF0-OSC_IN`**（并联 **C12 15pF 到 GND**）；
   * `3 脚` $\to$ **`PF1-OSC_OUT`**（并联 **C13 15pF 到 GND**）；
   * `2 脚, 4 脚` $\to$ **`GND`**（金属屏蔽外壳接地）。
3. **指示灯电路**：
   * **LED1 (电源绿灯)**：`+3V3` $\to$ **R6 (1k)** $\to$ **KT-0603G 阳极** $\to$ 阴极接 **`GND`**；
   * **LED2 (运行蓝灯)**：`+3V3` $\to$ **R10 (1k)** $\to$ **KT-0603B 阳极** $\to$ 阴极挂 **`LED_STATUS`** (接 PC13)。
4. **BAT_SENSE (电池分压采样)**：
   * `VBAT` $\to$ **R8 (10k)** $\to$ `中点 BAT_SENSE` (接 PC0) $\to$ **R17 (4.7k)** $\to$ `GND`；
   * 中点并联 **C15 (100nF)** 到 `GND` 滤波。
   * 满电 8.4V 采样计算：$V_{ADC} = 8.4\text{V} \times \frac{4.7}{10 + 4.7} = 2.685\text{V}$。

## 3. 💻 固件开发人员快速外设映射字典 (Firmware Pin Map)

```c
/**
 * @brief STM32G473RCT6 桌面自平衡小车底层引脚与外设映射
 */

// 1. 电机驱动与调速 (TB6612FNG)
#define MOTOR_L_PWM_PIN       GPIO_PIN_6   // PC6 (TIM3_CH1 / TIM8_CH1)
#define MOTOR_L_PWM_PORT      GPIOC
#define MOTOR_R_PWM_PIN       GPIO_PIN_7   // PC7 (TIM3_CH2 / TIM8_CH2)
#define MOTOR_R_PWM_PORT      GPIOC

#define MOTOR_L_IN1_PIN       GPIO_PIN_8   // PC8 (GPIO_OUT)
#define MOTOR_L_IN1_PORT      GPIOC
#define MOTOR_L_IN2_PIN       GPIO_PIN_9   // PC9 (GPIO_OUT)
#define MOTOR_L_IN2_PORT      GPIOC

#define MOTOR_R_IN1_PIN       GPIO_PIN_15  // PA15 (GPIO_OUT)
#define MOTOR_R_IN1_PORT      GPIOA
#define MOTOR_R_IN2_PIN       GPIO_PIN_0   // PB0 (GPIO_OUT)
#define MOTOR_R_IN2_PORT      GPIOB

#define MOTOR_STBY_PIN        GPIO_PIN_1   // PB1 (GPIO_OUT, High Enable)
#define MOTOR_STBY_PORT       GPIOB

// 2. 左右轮正交编码器测速 (AB相)
#define ENC_L_TIM             TIM2         // 32-bit Timer Encoder Mode
#define ENC_L_A_PIN           GPIO_PIN_0   // PA0 (TIM2_CH1)
#define ENC_L_B_PIN           GPIO_PIN_1   // PA1 (TIM2_CH2)

#define ENC_R_TIM             TIM1         // Advanced Timer Encoder Mode
#define ENC_R_A_PIN           GPIO_PIN_8   // PA8 (TIM1_CH1)
#define ENC_R_B_PIN           GPIO_PIN_9   // PA9 (TIM1_CH2)

// 3. 姿态传感器 ICM-42605 (SPI1 + EXTI)
#define IMU_SPI               SPI1
#define IMU_CS_PIN            GPIO_PIN_4   // PA4 (SPI1_NSS / GPIO_OUT)
#define IMU_SCK_PIN           GPIO_PIN_5   // PA5 (SPI1_SCK)
#define IMU_MISO_PIN          GPIO_PIN_6   // PA6 (SPI1_MISO)
#define IMU_MOSI_PIN          GPIO_PIN_7   // PA7 (SPI1_MOSI)
#define IMU_INT_PIN           GPIO_PIN_4   // PC4 (EXTI4 中断)

// 4. 外部存储 W25Q128 (SPI2)
#define FLASH_SPI             SPI2
#define FLASH_CS_PIN          GPIO_PIN_12  // PB12 (SPI2_NSS / GPIO_OUT)
#define FLASH_SCK_PIN         GPIO_PIN_13  // PB13 (SPI2_SCK)
#define FLASH_MISO_PIN        GPIO_PIN_14  // PB14 (SPI2_MISO)
#define FLASH_MOSI_PIN        GPIO_PIN_15  // PB15 (SPI2_MOSI)

// 5. ESP32-S3 通信串口 (USART2, 115200 / 921600 bps)
#define HOST_UART             USART2
#define HOST_TX_PIN           GPIO_PIN_2   // PA2 (USART2_TX)
#define HOST_RX_PIN           GPIO_PIN_3   // PA3 (USART2_RX)
```
