## 2. 🔌 主控板与 TB6612 驱动模块引脚对应表 (H1 插座)

主控板上的 **H1 接口** 引脚直接与 **TB6612FNG 驱动模块** 连接：

| 主控板 H1 引脚 | STM32 内部引脚 / 功能 | 连接至 TB6612 模块引脚 | 作用说明 |
| :---: | :---: | :---: | :--- |
| **PIN 1 (VBAT)** | 电池正极 (7.4V) | **VM** | 为电机提供 7.4V 动力电源 |
| **PIN 2 (GND)** | 电源地线 | **GND** | 电源共地 |
| **PIN 3** | **PC6 (TIM3_CH1)** | **PWMA** | 左电机 PWM 调速信号 |
| **PIN 4** | **PC7 (TIM3_CH2)** | **AIN1** | 左电机正反转控制方向 1 |
| **PIN 5** | **PC8 (TIM3_CH3)** | **BIN1** | 右电机正反转控制方向 1 |
| **PIN 6** | **PC9 (TIM3_CH4)** | **PWMB** | 右电机 PWM 调速信号 |
| **3.3V (J4引脚)**| 3.3V 逻辑电源 | **VCC + STBY** | 驱动芯片逻辑供电与使能 |

## 3. 🎯 核心控制算法：三闭环 PID 架构

自平衡机器人的控制核心是 **每 5ms 执行一次** 的 PID 计算：

```
最终电机输出 = 直立环 PID 输出 ± 速度环 PID 输出 ± 转向环 PID 输出
```

1. **直立环 PID（PD 控制，核心保证不倒）**：
   * 输入：ICM-42688 解算出的实际倾角与角速度；
   * 目标：保持车身倾角在机械中值（0°）；
   * 输出：快速调整车轮反向加速对抗倒伏趋势。
2. **速度环 PID（PI 控制，消除位移漂移）**：
   * 输入：左右轮霍尔编码器读取的实时车速；
   * 目标：根据遥控器手柄前后摇杆给出的设定速度移动；
   * 输出：平稳加减速并保持匀速移动。
3. **转向环 PID（P 控制，差速转弯）**：
   * 输入：遥控器左右摇杆的转向偏移量；
   * 输出：左轮与右轮形成差速，实现原地 360° 灵动自旋。
