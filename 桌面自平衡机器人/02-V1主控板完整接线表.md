# V1 桌面自平衡机器人主控板：完整接线表

> 版本：V1
>
> 目标：新设计机器人主控 PCB。旧无人机飞控 PCB 不使用，但复用已经购买的板载器件。
>
> 本文按“元件引脚 -> 目标元件引脚/网络”描述。网络标签同名即代表电气连接，不需要跨页面拉长线。

## 1. 总体电源架构

```text
2S 电池 7.4V（满电 8.4V）
  -> 外部 2 脚电源开关
  -> J1 电池输入
  -> VBAT
      -> U11 SY8120IABC -> +5V
          -> LDO2 ME6211 -> +3V3
      -> 电池电压分压 -> MCU ADC

外部 LM2596（已购买，调到 6.0V）
  -> 外部 TB6612 VM
  -> 两颗 6V N20 电机

主控板 +3V3
  -> STM32、ICM-42605、W25Q128、编码器逻辑、ToF、TB6612 VCC
```

重要：

- `VBAT` 是 2S 电池电压，范围 `7.4V~8.4V`。
- `+5V` 由板载 `SY8120IABC` 产生。
- `+3V3` 由 `ME6211` 产生。
- `TB6612 VM` 使用外部 LM2596 的 `6.0V`，不接 `VBAT`，不接主控板 `+5V`。
- `TB6612 VCC` 接主控板 `+3V3`。
- 所有 `GND` 必须共地。

## 2. 连接器和网络名称

### 2.1 J1：2S 电池输入

放置一个 2 Pin 连接器，例如 `HDR-M-2.54_1x2P`。

| 引脚 | 网络 | 连接 |
| --- | --- | --- |
| `J1-1` | `VBAT` | 外部开关后的电池正极 |
| `J1-2` | `GND` | 电池负极 |

### 2.2 主电源开关

外部开关串在电池正极：

```text
电池正极 -> 开关 -> J1-1 VBAT
电池负极 ------------> J1-2 GND
```

### 2.3 电源输出接口

建议放置以下接口，并在 PCB 丝印标注电压：

| 接口 | 引脚 |
| --- | --- |
| `J_5V_OUT` | `+5V, GND` |
| `J_3V3_OUT` | `+3V3, GND` |
| `J_EXT_I2C` | `+3V3, GND, I2C_SDA, I2C_SCL` |
| `J_EXT_UART` | `+3V3, GND, UART_TX, UART_RX` |
| `J_GPIO_EXT` | `+3V3, GND, GPIO_EXT1~GPIO_EXT6` |
| `J_SWD` | `+3V3, SWDIO, SWCLK, NRST, GND` |

## 3. U11：SY8120IABC 2S 转 5V

当前 EDA 符号引脚如下：

| U11 引脚 | 名称 |
| ---: | --- |
| 1 | `BS` |
| 2 | `GND` |
| 3 | `FB` |
| 4 | `EN` |
| 5 | `IN` |
| 6 | `LX` |

### 3.1 逐脚连接

```text
U11-5 IN -> VBAT
U11-4 EN -> VBAT
U11-2 GND -> GND
U11-6 LX -> L1-1
U11-3 FB -> R_FB_TOP-1 和 R_FB_BOTTOM-1 的连接点
U11-1 BS -> C_BOOT-1
C_BOOT-2 -> U11-6 LX
L1-2 -> +5V
```

### 3.2 输入和输出电容

```text
C_IN1 = 10uF
C_IN1-1 -> VBAT
C_IN1-2 -> GND

C_IN2 = 100nF
C_IN2-1 -> VBAT
C_IN2-2 -> GND

C_OUT1 = 10uF
C_OUT1-1 -> +5V
C_OUT1-2 -> GND

C_OUT2 = 100nF
C_OUT2-1 -> +5V
C_OUT2-2 -> GND
```

电容尽量靠近 U11 的 `IN/GND` 和电感 `L1` 的输出侧。

### 3.3 FB 分压

电阻接法：

```text
R_FB_TOP = 100k
R_FB_TOP-1 -> +5V
R_FB_TOP-2 -> FB_SENSE

R_FB_BOTTOM = 20k
R_FB_BOTTOM-1 -> FB_SENSE
R_FB_BOTTOM-2 -> GND

U11-3 FB -> FB_SENSE
```

`100k/20k` 是当前复用 BOM 的 5V 反馈分压候选值。投板前必须用 SY8120IABC 数据手册的反馈参考电压公式确认输出确实为 5V；如果公式要求不同阻值，只替换这两个电阻，不改变其他网络。

### 3.4 自举电容

```text
C_BOOT-1 -> U11-1 BS
C_BOOT-2 -> U11-6 LX
```

`C_BOOT` 使用已购的 `100nF` 或 `22nF`，**二者只能选一个**。当前旧图曾使用 `100nF`，BOM 也列过 `22nF`，存在资料不一致；必须以你手上 SY8120IABC 的准确数据手册为最终依据，确认后再锁定数值。不要把自举电容接到 GND。

## 4. LDO2：ME6211C33M5G-N，5V 转 3.3V

当前 EDA 符号引脚如下：

| LDO2 引脚 | 名称 |
| ---: | --- |
| 1 | `VIN` |
| 2 | `VSS` |
| 3 | `CE` |
| 4 | `NC` |
| 5 | `VOUT` |

逐脚连接：

```text
LDO2-1 VIN -> +5V
LDO2-2 VSS -> GND
LDO2-3 CE -> +5V
LDO2-4 NC -> 不接
LDO2-5 VOUT -> +3V3
```

去耦：

```text
C_LDO_IN = 10uF
一端 -> +5V
另一端 -> GND

C_LDO_OUT = 10uF
一端 -> +3V3
另一端 -> GND

C_LDO_HF = 100nF
一端 -> +3V3
另一端 -> GND
```

## 5. U9：STM32G473RCT6 电源和启动

### 5.1 电源脚

```text
U9-1 VBAT -> +3V3
U9-16 VDD -> +3V3
U9-28 VREF+ -> +3V3
U9-30 VDDA -> +3V3
U9-32 VDD -> +3V3
U9-64 VDD -> +3V3
```

```text
U9-15 VSS -> GND
U9-27 VSSA -> GND
U9-31 VSS -> GND
U9-47 VSS -> GND
U9-63 VSS -> GND
```

每个 `VDD` 附近放 `100nF` 去耦电容：

```text
每颗 C_100nF-1 -> +3V3
每颗 C_100nF-2 -> GND
```

`VDDA` 旁额外放 `1uF` 或已购 `10uF` 到 GND。若没有 1uF，V1 可使用 10uF，但要靠近 VDDA/VSSA。

### 5.2 晶振 X1

```text
U9 PF0-OSC_IN -> X1-1
U9 PF1-OSC_OUT -> X1-2
```

X1 另外两个脚按所选 4 脚晶振符号/封装处理：

```text
X1-3 -> GND
X1-4 -> GND
```

如果实际购买的是 2 脚无源晶振，则只接两端信号，不要凭 4 脚符号连接；必须按具体封装引脚图确认。

晶振负载电容：

```text
C_X1A = 15pF
一端 -> PF0-OSC_IN
另一端 -> GND

C_X1B = 15pF
一端 -> PF1-OSC_OUT
另一端 -> GND
```

### 5.3 复位、BOOT0、SWD

```text
U9-PG10-NRST -> NRST
NRST -> 10k -> +3V3
NRST -> 复位按键 -> GND（可选）

U9-PB8-BOOT0 -> 10k -> GND
U9-PB8-BOOT0 -> BOOT 跳线焊盘（可选，拉高进入系统 bootloader）
```

```text
U9-PA13 -> SWDIO
U9-PA14 -> SWCLK
J_SWD -> +3V3, SWDIO, SWCLK, NRST, GND
```

## 6. U10：ICM-42605 IMU

U10 当前符号引脚：

| U10 引脚 | 名称 | 连接 |
| ---: | --- | --- |
| 1 | `AP_SDO/AP_AD0` | `IMU_MISO` -> U9 PA4 |
| 2 | `RESV` | 不接 |
| 3 | `RESV` | 不接 |
| 4 | `INT1/INT` | `IMU_INT` -> U9 PC4 |
| 5 | `VDDIO` | +3V3 |
| 6 | `GND` | GND |
| 7 | `RESV` | 不接 |
| 8 | `VDD` | +3V3 |
| 9 | `INT2/FSYNC` | 不接 |
| 10 | `RESV` | 不接 |
| 11 | `AP_CS` | `IMU_CS` -> U9 PA5 |
| 12 | `AP_SCL/AP_SCLK` | `IMU_SCK` -> U9 PA6 |
| 13 | `AP_SDA/AP_SDIO/AP_SDI` | `IMU_MOSI` -> U9 PA7 |
| 14 | `AP_SDA/AP_SDIO/AP_SDI` | 按所选 ICM-42605 封装/模式处理，不可与 13 脚重复硬短接 |

ICM-42605 的 SPI/SDIO 复用脚必须按你购买的芯片数据手册和 EDA 封装确认。原飞控图中曾将相关 AP_SDA/AP_SDIO 引脚并列显示，不能仅凭符号名称判断是否需要短接。

去耦：

```text
C_IMU1 = 100nF：U10 VDD -> GND
C_IMU2 = 100nF：U10 VDDIO -> GND
```

IMU 电源和信号线不要接 5V。

## 7. U13：W25Q128JVSIQ Flash

| U13 引脚 | 名称 | 连接 |
| ---: | --- | --- |
| 1 | `CS#` | `FLASH_CS` -> U9 PB12 |
| 2 | `DO` | `FLASH_MISO` -> U9 PB14 |
| 3 | `IO2` | 不接或按 Quad-SPI 方案预留 |
| 4 | `GND` | GND |
| 5 | `DI` | `FLASH_MOSI` -> U9 PB15 |
| 6 | `CLK` | `FLASH_SCK` -> U9 PB13 |
| 7 | `IO3` | 不接或按 Quad-SPI 方案预留 |
| 8 | `VCC` | +3V3 |

```text
C_FLASH = 100nF
一端 -> U13 VCC
另一端 -> GND
```

V1 使用普通 SPI 时，`IO2`、`IO3` 不接；若 EDA ERC 报未连接，放 No Connect 标记。

## 8. USB-C：USBC2

USB-C 只作为 STM32 下载/调试 USB，**不作为 2S 电池充电口**。

### 8.1 电源和外壳脚

```text
USBC2 A1/B12 GND -> GND
USBC2 A4/B9 VBUS -> USB_VBUS（先不接 +5V）
USBC2 EH1/EH2/EH3/EH4 -> GND
```

`USB_VBUS` 暂不与 `VBAT`、`+5V`、`+3V3` 相连，避免 USB 与板上电源互相顶电。若后续需要 USB 插入时给板子供电，再单独设计电源 OR-ing。

### 8.2 数据脚

```text
USBC2 A6 与 B6 短接 -> USB_DP -> U9 PA12
USBC2 A7 与 B7 短接 -> USB_DM -> U9 PA11
```

### 8.3 CC 脚

需要 2 颗已购 `5.1k` 电阻：

```text
USBC2 A5 CC1 -> R_CC1 5.1k -> GND
USBC2 B5 CC2 -> R_CC2 5.1k -> GND
```

```text
USBC2 A8 SBU1 -> 不接
USBC2 B8 SBU2 -> 不接
```

若 Type-C 符号把 A6/B6、A7/B7 已经合并为同一引脚，按符号实际引脚连接即可，不要重复短接。

## 9. TB6612FNG 外部模块接口

主控板不放 TB6612 芯片，只放连接器。建议 `J_TB` 至少 10 针：

| J_TB 网络 | 连接 |
| --- | --- |
| `VM_6V` | 外部 LM2596 输出 6.0V，接 TB6612 VM |
| `+3V3` | TB6612 VCC |
| `GND` | TB6612 GND |
| `MOTOR_PWMA` | TB6612 PWMA |
| `MOTOR_AIN1` | TB6612 AIN1 |
| `MOTOR_AIN2` | TB6612 AIN2 |
| `MOTOR_PWMB` | TB6612 PWMB |
| `MOTOR_BIN1` | TB6612 BIN1 |
| `MOTOR_BIN2` | TB6612 BIN2 |
| `MOTOR_STBY` | TB6612 STBY |

STM32 分配：

```text
U9 PC6 -> MOTOR_PWMA
U9 PC7 -> MOTOR_PWMB
U9 PC8 -> MOTOR_AIN1
U9 PC9 -> MOTOR_AIN2
U9 PA15 -> MOTOR_BIN1
U9 PB0 -> MOTOR_BIN2
U9 PB1 -> MOTOR_STBY
```

`MOTOR_STBY` 增加 `10k` 下拉到 GND，保证 MCU 复位时驱动关闭。这个 `10k` 可复用已有 BOM。

## 10. N20 编码器接口

每颗编码器至少需要：`+3V3、GND、ENC_A、ENC_B`。

### 左电机

```text
J_ENC_L-1 -> +3V3
J_ENC_L-2 -> GND
J_ENC_L-3 -> ENC_L_A -> U9 PA0
J_ENC_L-4 -> ENC_L_B -> U9 PA1
```

### 右电机

```text
J_ENC_R-1 -> +3V3
J_ENC_R-2 -> GND
J_ENC_R-3 -> ENC_R_A -> U9 PA8
J_ENC_R-4 -> ENC_R_B -> U9 PA9
```

电机动力线不经过主控板逻辑接口，接法为：

```text
TB6612 AO1/AO2 -> 左 N20 电机两根动力线
TB6612 BO1/BO2 -> 右 N20 电机两根动力线
```

编码器实际线序、电平和是否需要外部上拉，必须以电机到货后的说明/实测为准。若编码器输出为开漏，再为 A/B 各加 `4.7k` 上拉到 `+3V3`；若模块已内置上拉，不重复加。

## 11. ESP32-S3 接口

```text
J_ESP32-1 -> +5V 或按开发板允许电压供电
J_ESP32-2 -> GND
J_ESP32-3 -> STM_TX -> U9 PA2 / USART2_TX
J_ESP32-4 -> STM_RX -> U9 PA3 / USART2_RX
```

UART 必须交叉：

```text
STM32 TX -> ESP32 RX
STM32 RX -> ESP32 TX
```

ESP32 不直接连接 TB6612 的 PWM、方向和 STBY。

## 12. VL53L0X 前向测距接口

```text
J_TOF-1 -> +3V3
J_TOF-2 -> GND
J_TOF-3 -> TOF_SDA -> U9 PB7 / I2C1_SDA
J_TOF-4 -> TOF_SCL -> U9 PB6 / I2C1_SCL
```

预留但 V1 可不装：

```text
J_TOF-5 -> TOF_XSHUT -> 空闲 GPIO
J_TOF-6 -> TOF_INT -> 空闲 GPIO
```

I2C 上拉：

```text
TOF_SDA -> 4.7k -> +3V3
TOF_SCL -> 4.7k -> +3V3
```

可复用旧 BOM 的 `4.7k` 电阻。若 VL53L0X 模块已经自带上拉，主控板上不要重复装；可将上拉电阻做成可选焊盘。

## 13. 电池电压检测

使用已有 `10k` 电阻：

```text
VBAT -> R_BAT_TOP 10k -> BAT_SENSE -> R_BAT_BOTTOM 10k -> GND
BAT_SENSE -> 100nF -> GND
BAT_SENSE -> U9 PC0 / ADC
```

2S 满电 8.4V 时，两个 10k 分压后为约 4.2V，**超过 STM32 3.3V ADC 上限**，不能直接使用这个比例。

因此必须改为以下任一方案：

- 使用已有 `100k + 47k`，满电 ADC 约 `2.88V`；或
- 使用 `100k + 47k` 作为上/下分压，并用 `100nF` 滤波；或
- 重新购买合适阻值。

推荐复用 BOM：

```text
VBAT -> 100k -> BAT_SENSE -> 47k -> GND
BAT_SENSE -> 100nF -> GND
BAT_SENSE -> U9 PC0
```

这组阻值必须在原理图中使用，不能继续使用 `10k/10k`。

## 16. 画图顺序

按以下顺序在嘉立创 EDA 中连接，每完成一组再进行 ERC：

1. `J1 -> U11`：VBAT、GND、IN、EN。
2. `U11`：BS/LX 自举、LX/L1/+5V、FB 分压、输入/输出电容。
3. `LDO2`：+5V 输入、+3V3 输出、CE、输入/输出电容。
4. `U9`：全部电源脚、GND、去耦、晶振、NRST、BOOT0、SWD。
5. `U10`：SPI、INT、3V3、GND、去耦。
6. `U13`：SPI、3V3、GND、去耦。
7. `USBC2`：USB DP/DM、CC1/CC2、GND。
8. `J_TB`：PWM、方向、STBY、3V3、GND、VM_6V。
9. `J_ENC_L/J_ENC_R`：3V3、GND、AB 相。
10. `J_ESP32`、`J_TOF`、扩展 I2C/UART/GPIO。
11. 电池 ADC 分压。
12. ERC、网络检查和芯片数据手册复核。

在第 1 至第 3 步完成并确认 `+5V`、`+3V3` 电源网络后，再开始连接 MCU，避免电源网络名称混乱。
