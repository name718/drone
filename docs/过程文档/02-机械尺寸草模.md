# 02 机械尺寸草模

## 目标

用 CAD 验证器件能否放下、重心是否合理、结构能否装配和维护。

## 主要任务

- 建立电机中心距、螺旋桨扫掠范围和机臂模型；
- 加入电池、电调、飞控和接收机的真实包络尺寸；
- 确定 PCB 外形、安装孔、螺柱高度和线束方向；
- 预留 3D 打印件的装配间隙、保护结构和维修空间。

## 输出物

尺寸草模、安装孔位图、重心估算、器件布局图。此阶段不追求外观和轻量化。

## V1 成品方案

V1 的 130 mm 方案比例不合理，已停止使用并保留作对比：[机械成品方案.blend](机械成品方案.blend)。V2 到 V4 为中间验证版本。当前装配与打印基线为 [机械成品方案-V5.blend](机械成品方案-V5.blend)。

当前冻结的设计基线：

| 项目 | V5 参数 |
| --- | --- |
| 电机对角中心距 | 180 mm |
| 螺旋桨包络 | 3.5 英寸 / 88.9 mm，桨尖间隙约 38.4 mm |
| 机架形式 | X 型、一体式底架与分层设备舱 |
| 电机安装孔 | M2，12 x 12 mm，8 mm 中心避让孔 |
| 飞控外形 | 36 x 36 mm |
| 飞控/电调堆叠孔 | 30.5 x 30.5 mm，M3 |
| 电池包络 | 2S，60 x 30 x 17 mm，底板下方纵向安装 |
| 设备层级 | 下置电池、居中四合一电调、上层飞控 |
| 电池固定 | 两组扎带，穿过底架四个 5 x 12 mm 槽 |
| 前部 | ELRS 接收机；摄像头和图传后续设计 |
| 底部 | 首版不安装 ToF，稳定飞行后再设计安装件 |

当前模型是装配原型。实际飞行前仍需用实物或厂家图纸复核电机孔距、电池尺寸、电调高度、连接器方向和螺柱规格。

## V5 首批打印件

打印目录仅保留 [lower_frame-V5.stl](打印件/lower_frame-V5.stl)。底架约 153.28 x 153.28 x 5.40 mm，机臂宽 16 mm，电机座直径 26 mm。

STL 已重新导入 Blender 审计：单对象、单连通壳体、非流形边 0、开放边界 0。它可以用于低成本原型试装，但孔距仍需在购买实物后复核。
