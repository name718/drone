## 3. 🛒 建议分批采购策略（零经济压力推进）

为了防止一次性投入过多，建议分两阶段采购：

### 阶段一：地面台架调试（总花费约 150 元）
1. 采购 **贴片电子元器件**（芯片、阻容、接插件，约 95 元）；
2. 采购 **富斯 i6 摇杆一对 + 1.8寸屏幕 + 1S电池**（约 43 元）；
3. 采购 **DAP-Link 烧录器**（约 15 元）；
* **目标**：在桌面上完成飞控板、遥控器裸板焊接、固件烧录、摇杆 ADC 采样与屏幕 UI 显示。

### 阶段二：四轴装机与室外飞行（总花费约 240 元）
1. 采购 **4 个 1104 无刷电机 + 20A 电调 + 碳纤机架 + 螺旋桨**（约 116 元）；
2. 采购 **ELRS 发射机 + ELRS 接收机**（约 74 元）；
3. 采购 **2S 450mAh 动力电池 + B3 平衡充**（约 43 元）；
* **目标**：完成四轴整机组装、DShot 电机旋转测试、双向对频与首飞试飞。
