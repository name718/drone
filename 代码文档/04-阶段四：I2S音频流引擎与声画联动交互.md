> **阶段目标**：掌握 I2S 硬件总线通信时序与数字音频流原理，完成 MAX98357A 扬声器播放与 INMP441 麦克风录音全双工驱动，实现基于双核多任务的视听联动拟人交互。

---

## 1. I2S 数字音频通信协议底层物理机制

### 1.1 为什么选择 I2S 协议？
- **普通 PWM/DAC 缺陷**：易受 MCU 电源高频杂波干扰，底噪大、失真高。
- **I2S (Inter-IC Sound)**：飞利浦专为高保真数字音频设计的 3 线串行通信标准，纯数字传输，具备 **0 底噪、CD 级保真度**。

### 1.2 I2S 核心三线信号定义
```text
  BCLK (位时钟, GPIO 16) ───┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌──
                            └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘  
  LRC  (帧同步, GPIO 17) ───┐                               ┌────────
                            └───────────────────────────────┘        
                             ◄────── 左声道 ──────► ◄────── 右声道 ─────►
  DIN  (串行数据, GPIO 15) ──[ MSB ][ Bit 14 ] ... [ LSB ] [ MSB ] ...
```
1. **`BCLK` (Bit Clock)**：位时钟，每个采样点的每一个 bit 对应一个 BCLK 时钟脉冲。
2. **`LRC` / `WS` (Word Select)**：左右声道切换与帧同步信号。`LRC = 0` 传输左声道数据，`LRC = 1` 传输右声道数据；其频率严格等于音频**采样率**（16000 Hz）。
3. **`DIN` / `DOUT` (Serial Data)**：按位流式传输补码形式的 16-bit 线性 PCM 音频数据。

## 2. ESP32-S3 双 I2S 控制器全双工架构

ESP32-S3 内部集成了两套完全独立的硬件 I2S 外设控制器：
- **`I2S_NUM_1` (音频输出 / 嘴巴)**：专门挂载 MAX98357A 功放芯片，负责 DMA 发送数据流。
- **`I2S_NUM_0` (音频输入 / 耳朵)**：专门挂载 INMP441 麦克风芯片，负责 DMA 接收数据流。
- **核心优势**：两个硬件外设各自拥有独立的 DMA 环形缓冲区，支持真正的“边说话边听声”（全双工无阻塞并发）。

## 3. 音频输出 (MAX98357A) 核心算法与消除杂音实践

### 3.1 32-bit Slot 物理槽位对齐（消除白噪音与沙沙声）
- **现象与机理**：MAX98357A 硬件解码器要求每个音频采样点在总线上占据 **32 个 BCLK 时钟周期（32-bit Slot）**。若配置为默认的 16-bit Slot，时钟鉴相器发生采样错位，产生极大的数字沙沙声。
- **配置规范**：
  ```cpp
  i2s_std_slot_config_t slot_cfg = I2S_STD_PHILIPS_SLOT_DEFAULT_CONFIG(
      I2S_DATA_BIT_WIDTH_16BIT, I2S_SLOT_MODE_STEREO);
  slot_cfg.slot_bit_width = I2S_SLOT_BIT_WIDTH_32BIT; // 关键：每声道32 BCLK，全帧64 BCLK
  ```

### 3.2 数学正弦波合成与平滑包络算法 (Fade-in / Fade-out)
- **正弦波合成公式**：
  $$y[i] = A \cdot \sin\left(\frac{2\pi \cdot f \cdot i}{\text{SampleRate}}\right)$$
- **消除截断爆音 (Pop Noise)**：在波形的前 10% 和后 10% 引入线性平滑包络系数（`envelope: 0.0 -> 1.0 -> 0.0`），让声音平滑起步与收尾，杜绝波形突变产生的喇叭膜片爆震。

## 4. 音频输入 (INMP441) 录音与音量能量计算

### 4.1 单声道左槽位硬件抽取
- INMP441 的 `L/R` 引脚接地（GND），有效声音位于**左声道**。
- 设置 `slot_mask = I2S_STD_SLOT_LEFT`，ESP32 硬件只抽取有效左声道数据，自动丢弃右声道空白，**节省 50% DMA 内存开销**。

### 4.2 音量分贝能量计算公式 (`calculateVolume`)
通过计算一帧音频（512 点）的平均绝对幅值（Mean Absolute Amplitude）归一化至 $0 \sim 100$：
$$\text{Volume} = \left(\frac{1}{N}\sum_{i=0}^{N-1} |y[i]|\right) \times \frac{100}{\text{MaxAmplitude}}$$
- 安静环境：$0 \sim 5\%$；
- 说话声/吹气：$20 \sim 80\%$。
