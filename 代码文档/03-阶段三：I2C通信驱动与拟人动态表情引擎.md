# 📚 阶段三：I2C 通信驱动与拟人动态表情引擎 (FaceEngine)

> **阶段目标**：掌握 I2C 物理层时序与 SSD1306 OLED 显存映射数学算法，运用现代 C++ 面向对象封装硬件驱动，实现具备随机自然眨眼与多情绪切换的拟人表情引擎。

---

## 1. I2C 通信协议底层物理机制

### 1.1 双线开漏结构 (Open-Drain)
- `SDA`（串行数据线，GPIO 8）与 `SCL`（串行时钟线，GPIO 9）。
- 两根信号线空闲时均通过 3.3V 上拉电阻维持高电平。
- 芯片发送 `0` 时内部晶体管导通拉低到地，具备天然的“线与”防短路特性，支持总线挂载多个从机设备。

### 1.2 标准通信时序帧
```text
  SCL ──┐   ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐   ┌──
        └───┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─┘ └───┘  
  SDA ──┐     ┌───────────────────────┐   ┌───┐   ┌──
        └─────┴───────────────────────┴───┘   └───┘  
       START       7位从机地址(0x3C) + W(0)  ACK  STOP
```
1. **START 起始位**：SCL 高电平期间，SDA 产生下降沿。
2. **7 位从机地址 + 写标志**：发送 `0x3C` (`0111100b`) + 第 8 位 `0`（写）。
3. **ACK 应答位**：第 9 个时钟周期，从机 OLED 主动拉低 SDA 确认响应。
4. **数据传输**：首字节 `0x00` 代表控制命令，首字节 `0x40` 代表显存数据。
5. **STOP 停止位**：SCL 高电平期间，SDA 产生上升沿释放总线。

## 2. SSD1306 0.96寸 OLED 显存映射与帧缓冲算法

### 2.1 分页结构 (Page Addressing)
- 屏幕分辨率：128 列 × 64 行 = 8192 个发光像素点。
- 垂直方向每 8 行打包为 1 个 Page（Page 0 ~ Page 7 共 8 页），每页 128 字节：
  $$\text{全屏显存容量} = 128 \times 8 = 1024 \text{ 字节 (1 KB)}$$

### 2.2 像素坐标 $(x, y)$ 映射数学公式 (`drawPixel`)
要在屏幕任意坐标 $(x, y)$ 点亮或熄灭像素：
1. **显存字节索引**：
   $$\text{index} = x + \left(\frac{y}{8}\right) \times 128$$
2. **字节内位偏移**：
   $$\text{bit\_pos} = y \pmod 8$$
3. **位运算操作**：
   - 点亮：`m_buffer[index] |= (1 << bit_pos);`
   - 熄灭：`m_buffer[index] &= ~(1 << bit_pos);`

### 2.3 全屏帧缓冲 (FrameBuffer) 的必要性
- **直写方案**：画一双眼睛需要发起数千次 I2C 寻址，导致屏幕产生明显的上下撕裂与闪烁，帧率不足 5 FPS。
- **帧缓冲方案**：所有画线、圆角矩形在单片机 1024 字节内存数组中纳秒级完成，通过 I2C 批量流式写入，帧率稳定在 **30~50 FPS**，画质如丝般顺滑。

### 2.4 数据手册核心指令与升压电荷泵
- **`0x8D, 0x14` (Charge Pump Setting)**：**最核心指令！** 开启芯片内部 7.5V 升压电荷泵（3.3V 供电下必开，否则点不亮）。
- **`0x20, 0x00`**：水平寻址模式，写入后列地址自动自增，跨页自动换行。
- **`0xA1` / `0xC8`**：左右段重映射与上下行扫描翻转，适配正立视觉。

## 3. 现代 C++ 嵌入式面向对象实践

1. **`constexpr` 编译期常量**：`static constexpr uint8_t SCREEN_WIDTH = 128;` 替代传统无类型 `#define` 宏，提供严格类型检查和类作用域保护。
2. **引用传递 (`&`)**：`FaceEngine(OledDriver& oled)` 接收硬件引用，杜绝 1KB 显存对象的深拷贝，内存开销为 0。
3. **`explicit` 构造函数**：阻止单参数构造函数的隐式类型转换。
4. **强类型枚举 (`enum class`)**：`EmotionState::NORMAL` 避免传统 `enum` 污染全局命名空间，禁止隐式转整型。
5. **三层解耦设计**：
   - `main.cpp`（业务状态机） ➔ `FaceEngine`（拟人动画模型） ➔ `OledDriver`（物理 I2C 通信），软硬件完全解耦。

## 4. 拟人动态表情引擎算法

### 4.1 拟人眨眼随机状态机
- 每次眨眼完成后，生成下一次眨眼的随机等待期：
  $$\text{Interval} = 2000\text{ms} + (\text{rand()} \pmod{2500})\text{ms} \quad (2.0\text{s} \sim 4.5\text{s})$$
- 眨眼过程由 6 帧极速微动画组成：`{32, 20, 8, 3, 18, 32}` 像素高度变化序列。

### 4.2 动态居中插值公式
$$\text{current\_y} = \text{EYE\_CENTER\_Y} - \frac{\text{current\_height}}{2} = 32 - \frac{h}{2}$$
保证眼睛垂直中心轴稳定在 $Y=32$，逼真模拟生物眼睑由上下两侧向中心自然闭合。

### 4.3 几何圆角矩形算法
- 利用勾股定理判定圆角边界：$dx^2 + dy^2 \le r^2$；
- 封装实心填充 `fillRoundRect` 与空心线条 `drawRoundRect`，精准呈现圆润大眼与弯弯月牙笑眼。
