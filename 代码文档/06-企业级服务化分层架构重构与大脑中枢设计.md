# 📚 阶段六：企业级面向对象服务化架构 (SOA) 重构与大脑中枢设计

> **重构目标**：告别单片机新手常见的“所有代码塞在 main.cpp”的反模式（Anti-Pattern），遵循高内聚、低耦合的工业级面向对象设计模式（OOP & SOA），将大脑固件重构成清晰的分层服务体系，使 `main.cpp` 精简至 20 行以内。

---

## 1. 为什么必须进行架构重构？

### 1.1 传统单片机开发缺陷 (Anti-Pattern)
- 在 `main.cpp` 中定义大量全局变量与零散函数；
- 任务与任务之间强耦合，难以单元测试与独立移植；
- 代码量膨胀后极易引发全局变量冲突与多线程竞争死锁。

### 1.2 企业级 SOA 服务化架构优势
- **单一职责原则 (SRP)**：视觉、音频、运动通信各司其职，各自管理内部线程与硬件生命周期；
- **单例中枢调度 (Singleton & Facade)**：通过 `RobotBrain` 统一完成系统诊断、服务初始化与事件分发；
- **极简入口**：`main.cpp` 只保留 20 行标准总装入口，清爽、规范、优雅。

## 3. 各服务核心职责与接口一览

### 3.1 视觉服务 (`DisplayService`)
- **文件**：`display/display_service.hpp` & `.cpp`
- **职责**：封装底层 I2C OLED 驱动与 FaceEngine 拟人表情引擎，托管 Core 1 的 33 FPS 丝滑动画渲染线程。
- **对外 API**：
  ```cpp
  esp_err_t init();
  esp_err_t start();
  void setEmotion(EmotionState emotion);
  ```

### 3.2 音频服务 (`AudioService`)
- **文件**：`audio/audio_service.hpp` & `.cpp`
- **职责**：统一管理 MAX98357A 扬声器 (I2S1) 与 INMP441 麦克风 (I2S0)，提供全双工播音、数学纯音合成与环境分贝能量计算。
- **对外 API**：
  ```cpp
  esp_err_t init();
  void playBootSound();
  void playTone(float freq_hz, uint32_t duration_ms, float volume = 0.4f);
  size_t readRecordFrame(int16_t* out_buffer, size_t samples_to_read);
  static float calculateVolume(const int16_t* buffer, size_t samples);
  ```

### 3.3 运动通信服务 (`MotionService`)
- **文件**：`comm/motion_service.hpp` & `.cpp`
- **职责**：封装 UART2 串口驱动与协议有限状态机解析器，托管 Core 1 的 50Hz 周期控制下发与状态接收线程，提供超时平稳刹车保护。
- **对外 API**：
  ```cpp
  esp_err_t init();
  esp_err_t start();
  void setTargetVelocity(int16_t speed_mms, int16_t yaw_mrads, uint32_t duration_ms = 0);
  void stop();
  RobotStatePacket_t getLatestState() const;
  ```

### 3.4 大脑总控中枢 (`RobotBrain`)
- **文件**：`core/robot_brain.hpp` & `.cpp`
- **职责**：采用单例设计模式，执行芯片级内存自检（Flash、8MB PSRAM、SRAM），协同启动所有多核多任务服务，并在 Core 0 运行全局人机交互协调逻辑。

## 4. 重构后的极简 `main.cpp`

```cpp
/**
 * @file main.cpp
 * @brief 桌面自平衡机器人 · 大脑主控固件程序入口 (企业级极简规范)
 */

#include "robot_brain.hpp"

extern "C" void app_main(void) {
    // 1. 获取机器人大脑中枢单例引用
    auto& brain = RobotBrain::getInstance();

    // 2. 执行硬件自检与各子服务初始化
    brain.init();

    // 3. 一键点火启动多核任务与交互调度引擎
    brain.start();
}
```
