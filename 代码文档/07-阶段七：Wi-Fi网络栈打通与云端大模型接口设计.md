# 📚 阶段七：Wi-Fi 网络栈打通与云端大模型接口设计

> **阶段目标**：掌握 ESP32-S3 Station 模式网络协议栈驱动与事件循环机制，实现 NVS 射频校准加载、自动重连与 DHCP 动态 IP 分配，打通单片机连接 Internet 与接入云端大模型（LLM）的底层网络通路。

## 2. Wi-Fi 事件状态机与自动重连机制

### 2.1 事件驱动流转
1. **`WIFI_EVENT_STA_START`**：底层驱动启动完成，自动触发 `esp_wifi_connect()` 发起连接；
2. **`WIFI_EVENT_STA_DISCONNECTED`**：热点异常断开或密码错误，自动触发清除事件位并毫秒级周期重连；
3. **`IP_EVENT_STA_GOT_IP`**：成功通过 DHCP 协议从路由器获取到有效 IPv4 地址，置位 `WIFI_CONNECTED_BIT` 并通知业务层。

### 2.2 嵌入式零内存碎片设计
- 回调与接口均采用标准 `const char*` 传递 IP 与 SSID，杜绝 `std::string` 在频繁网络事件中产生堆内存碎片。

## 3. 实机联网验证结果

- **连接热点**：`CMCC-eGK3`
- **分配 IP 地址**：`192.168.1.169`
- **声画联动反馈**：
  - 成功获取 IP 瞬间，触发 Core 1 OLED 屏幕切换为 **开心月牙微笑眼（`EmotionState::HAPPY`）**；
  - 触发 Core 0 扬声器播放 **1046.5Hz (高音 C6)** 清脆联网成功提示音。
